# 20 · POS 收银界面设计

> 上一份：[19 KDS 界面](./19-KDS界面详细设计.md)｜下一份：[21 小程序顾客端](./21-小程序顾客端界面设计.md)

**一句话**：开台 → 点单 → 挂单 → 结账 → 交班，熟练店员的整单操作不超过 30 秒。

---

## 1. 目标

| 目标 | 度量 |
| --- | --- |
| 高峰期不卡手 | 开台到结账不超过 30 秒 |
| 输入方式齐全 | 触屏、键盘、扫码枪均可完成全流程 |
| 断网可用 | 开台、点单、挂单可离线，恢复后自动同步 |
| 金额零差错 | 所有金额来自服务端试算 |

---

## 2. 布局

| 区域 | 内容 |
| --- | --- |
| 顶部 | 门店、收银员、桌台 / 订单 / 交班 / 设置 |
| 左侧 60% | 桌台视图（默认）或菜单视图（点单时） |
| 右侧 40% | 当前订单明细、计价与操作 |
| 底部 | 快捷键提示 |

基准分辨率 1280×800，最低适配 1024×768。

---

## 3. 桌台总览

按区域分组（大厅、包间、露台），每张桌卡展示桌号、人数、就餐时长与金额，状态用颜色 + 文字双重表达：

| 状态 | 样式 | 说明 |
| --- | --- | --- |
| 空闲 | 白底灰框 | 可直接开台 |
| 使用中 | 绿底 | 显示时长与金额 |
| 待清台 | 橙底 | 角标提示，不闪烁 |

> 桌台状态只有三种，与 [12](./12-枚举与数据字典总表.md) 的 `table_status` 一致；预订不在本期范围。

**交互**

| 操作 | 结果 |
| --- | --- |
| 点空闲桌 | 直接开台并进入点单 |
| 点使用中桌 | 打开该桌订单栏 |
| 长按使用中桌 | 加人、并桌、转台、清台 |
| 扫码枪扫桌码 | 等同点击该桌 |

---

## 4. 点单

左侧切换为菜单：分类导航 + 菜品卡（名称、价格、沽清置灰、已加购数量角标）。

**选规格与加料**：弹窗内完成规格（必选）、加料组（必选或可选）、备注与数量；
必选组未选时禁止加入；加料加价实时反映到单价。

**提效设计**

- 扫码枪扫条码直接加购，免点击。
- 快捷键完成开台、结账、挂单、取单、交班。
- 单击加购、长按改数量，减少弹窗。
- 常用菜品可收藏置顶。

---

## 5. 挂单与取单

- 挂单：暂存当前订单（本地与服务端各一份），桌台保持使用中。
- 取单：从挂单列表选回继续点单，列表按时间倒序，显示桌号、金额、时长。

---

## 6. 并单、拆单与转台

| 功能 | 规则 |
| --- | --- |
| 并单 | 选源桌与目标桌，明细归并后重算金额 |
| 拆单 | 按人或按项拆分，生成多张支付单（AA） |
| 转台 | 迁到目标空闲桌，订单与桌台状态同步迁移 |
| 换桌 | 桌台故障时迁到备用桌 |

---

## 7. 结账

弹窗按「商品小计 → 优惠明细 → 应付 → 支付方式 → 实收找零」排列；
优惠明细逐项展示（活动、券、积分、储值），金额以服务端试算为准。

| 支付方式 | 交互 |
| --- | --- |
| 微信 / 支付宝 | 主扫展示收款码，被扫用扫码枪扫付款码 |
| 储值卡 | 手机号查会员 → 显示余额 → 扣减，不足提示 |
| 现金 | 输入实收，自动算找零 |
| 组合支付 | 储值卡 + 第三方补差 |

**结账后**：自动打结账单，桌台置「待清台」，会员积分与成长值入账。

---

## 8. 交班

展示班次信息与分类汇总（订单数、各支付方式金额、退款金额、合计），输入实际现金后自动算长短款。

- 长短款不为 0 时必须填写说明。
- 交班后打印交班单，数据不可再修改。

---

## 9. 弱网与离线

| 场景 | 表现 |
| --- | --- |
| 网络中断 | 顶部黄条「离线模式，数据将自动同步」 |
| 离线可做 | 开台、点单、挂单、加菜（本地暂存） |
| 离线不可做 | **结账支付**、会员查询、券核销 |
| 恢复 | 自动批量同步，冲突以服务端为准，重复单去重 |
| 同步失败 | 展示待同步列表，可手动重试 |

---

## 10. 异常处理

| 异常 | 处理 |
| --- | --- |
| 支付失败 | 明确原因，可换方式重试，订单不关闭 |
| 储值余额不足 | 提示差额并建议组合支付 |
| 桌台被其他终端占用 | 提示并刷新桌台状态 |
| 打印失败 | 提示可重打，不影响结账 |
| 同步冲突 | 展示差异，人工选择保留 |

---

## 11. 快捷键

| 键 | 功能 |
| --- | --- |
| F1 | 开台 |
| F2 | 结账 |
| F3 | 挂单 |
| F4 | 取单 |
| F5 | 刷新 |
| F8 | 交班 |
| F9 | 打印上一单 |
| Esc | 关闭弹窗 |
| Enter | 确认 |
| + / − | 数量增减 |

> 快捷键以本表为唯一口径，其他文档若与此冲突以本表为准。
