# 11 · 加盟结算与对账

> 上一份：[10 初始化与数据导入](./10-初始化与数据导入.md)｜下一份：[12 枚举与数据字典](./12-枚举与数据字典总表.md)

**一句话**：钱先进品牌账户，系统算清每家加盟商应收，财务按结算单打款；直营店只对账，不结算。

---

## 1. 业务模式

| 模式 | 资金归属 | 是否结算 |
| --- | --- | --- |
| 直营店 | 品牌总部 | 否，仅对账与考核 |
| 加盟店 | 加盟商（扣总部抽成） | 是 |
| 联营 / 合营 | 按协议分成 | 是 |

**一期资金路径（合规优先）**：顾客支付 → 品牌商户号 → 系统记账 → 计算应结 → 财务按结算单打款。

> 一期不做微信「分账直连」（需服务商资质与子商户进件），模型预留结算方式字段，二期可切换。

---

## 2. 核心概念

| 概念 | 定义 |
| --- | --- |
| 营收口径 | 默认取订单实付金额 |
| 分成基数 | 参与抽成的金额，可配为实付、实付减总部优惠、或商品原价 |
| 抽成 | 比例（万分比）与每单固定费，可组合 |
| 结算周期 | T+1 / 周结 / 月结 |
| 账期 | 结算单覆盖的交易时间范围 |
| 起结金额 | 低于该金额时累计到下一期 |
| 应结金额 | 营收 − 退款 − 抽成 + 补贴 − 其他扣项 |

---

## 3. 数据构成

| 表 | 用途 | 关键点 |
| --- | --- | --- |
| 加盟商 | 结算主体 | 联系人、公司、税号、开户行与账号（加密）、结算方式、状态 |
| 分成规则 | 抽成配置 | 作用范围（品牌默认 / 指定加盟商 / 指定门店）、基数、比例、固定费、周期、起结金额、优先级、生效区间 |
| 结算单 | 一期结算结果 | 加盟商、账期、订单数、营收、退款、抽成、补贴、其他扣项、应结、状态、打款凭证 |
| 结算明细 | 按日拆分 | 门店、业务日期、订单数、营收、抽成、退款、优惠承担方 |
| 门店日结 | 每日经营汇总 | 营收、优惠、退款、净额、支付方式构成、是否已结 |
| 交班记录 | 收银员班次 | 开班与交班时间、订单数、现金 / 线上 / 储值、退款、长短款、状态 |
| 对账主表 | 与渠道核对结果 | 日期、门店、渠道、双方笔数与金额、差异笔数与金额、状态 |
| 对账差异 | 差异明细 | 差异类型、订单号、渠道交易号、双方金额、处理状态与说明 |

---

## 4. 规则匹配与计算

**规则优先级**：指定门店 > 指定加盟商 > 品牌默认；同级取优先级数值最小者。
规则带生效区间，历史结算按当日生效规则，可复算。

**计算口径**：

```
营收 = 期内实付合计
退款 = 期内退款完成金额
基数 = 按规则取（实付 / 实付减总部优惠 / 商品原价）
抽成 = 基数 × 比例 + 固定费 × 单数
应结 = 营收 − 退款 − 抽成 + 补贴 − 其他扣项
```

- 营收按**支付成功日**归属，退款按**退款完成日**归属，不追溯修改已结账单。
- 跨期退款冲减当期，并备注原单号，保证账期不穿越。
- 结算单生成时快照实付金额与命中的规则，任何时点可重算复核。

---

## 5. 优惠由谁承担

| 优惠来源 | 承担方 | 对结算的影响 |
| --- | --- | --- |
| 品牌级活动 | 总部 | 加盟商不减收，计入总部补贴 |
| 品牌通用券 | 总部 | 同上 |
| 门店专属券 | 门店 | 直接减少营收 |
| 会员折扣 | 总部 | 计入总部补贴 |
| 积分抵扣 | 总部 | 计入总部补贴 |
| 储值卡余额消费 | 充值门店 / 品牌 | 按门店间清算 |

---

## 6. 储值卡跨店消费

顾客在 A 店充值、到 B 店消费，B 店没有真实现金流入，必须清算。

一期方案：充值资金统一进品牌账户；消费时记录消费门店，B 店计入营收，由总部资金池支付；
期末把钱包余额汇总为「储值负债」进财务报表。

> 二期可精细化到门店级清算，不改订单与钱包模型。

---

## 7. 对账

**三方对账**：业务系统 ↔ 支付渠道 ↔ 银行账户。

| 维度 | 频率 | 比对对象 |
| --- | --- | --- |
| 支付 | 每日 | 支付单 vs 渠道账单 |
| 退款 | 每日 | 退款单 vs 渠道退款账单 |
| 储值 | 每日 | 钱包流水 vs 充值流水 |
| 结算 | 每期 | 结算单 vs 打款记录 |
| 库存 | 每 5 分钟 | 缓存预扣 vs 数据库库存 |

**差异类型与处理**：

| 差异 | 原因 | 处理 |
| --- | --- | --- |
| 业务有、渠道无 | 回调丢失或未支付 | 主动查单，补单或关单 |
| 渠道有、业务无 | 已付款未落单 | 幂等补单或原路退回 |
| 金额不符 | 部分退款或优惠争议 | 核对退款单，按实际冲销 |
| 跨日边界 | 23:59–00:01 交易 | 以渠道账单归属日为准 |

---

## 8. 日结与交班

- 门店每日凌晨生成日结：营收、优惠、退款、净额、支付方式构成；重复生成需加锁。
- 交班记录按收银员统计现金、线上、储值、退款与长短款，交班后不可再修改。
- 日结与交班数据是结算与门店考核的依据，不允许手工改动，只能通过冲销单据修正。

---

## 9. 分账直连（二期）

| 维度 | 一期（后结算） | 二期（分账直连） |
| --- | --- | --- |
| 资金路径 | 全进品牌账户，财务打款 | 支付时直接分给子商户 |
| 资质 | 无 | 服务商资质 + 子商户进件 |
| 实时性 | 按周期 | 近实时 |
| 对账复杂度 | 低 | 高（需对分账流水） |

---

## 10. 定时任务

| 任务 | 频率 | 作用 |
| --- | --- | --- |
| 门店日结 | 每日凌晨 | 生成日结报表 |
| 支付与退款对账 | 每日 | 拉取渠道账单并比对 |
| 结算单生成 | 按周期 | 依据规则生成待确认结算单 |
| 储值负债快照 | 每日 | 汇总钱包余额 |
| 差异催办 | 每日 | 未处理差异提醒财务 |

---

## 11. 风控与合规

| 风险 | 对策 |
| --- | --- |
| 二清风险 | 资金进品牌账户、统一结算，不二次清算加盟商资金；分账直连需资质，一期不做 |
| 规则争议 | 分成规则版本化 + 生效区间 + 变更审计，结算单可复算 |
| 营收被篡改 | 订单与支付数据由系统生成，加盟商无写权限 |
| 储值负债 | 单卡余额上限、有效期与退款规则合规，负债进财报 |
| 打款错误 | 双人复核、账号加密、变更留痕 |
