# 19 · KDS 界面设计

> 上一份：[18 界面规范](./18-界面设计规范.md)｜下一份：[20 POS 收银](./20-POS收银界面设计.md)

**一句话**：4 米外看清桌号，一眼看出哪单最急，只有两个动作——全部出餐、划单。

---

## 1. 目标

| 目标 | 度量 |
| --- | --- |
| 远距离可读 | 桌号不小于 28px |
| 戴手套可点 | 主按钮高 48px、宽不低于卡片 60% |
| 一眼看出最急 | 超时置顶 + 红色左边框 |
| 零学习成本 | 只有两个主操作 |

---

## 2. 布局

| 区域 | 内容 |
| --- | --- |
| 顶部栏 | 门店、连接状态、待出与超时统计、时钟 |
| 卡片区 | 卡片平铺，默认 4 列，间距 16px |
| 底部栏 | 三色图例与排序说明 |

- 基准分辨率 1920×1080；21~24 寸一体机挂墙。
- KDS 无「档口」层级：门店一套后厨，订单整单一张卡。

---

## 3. 单卡结构

| 区域 | 内容 |
| --- | --- |
| 头部 | 桌号 + 订单类型 + 等待时长；下一行单号与下单时间 |
| 菜品行 | 菜品名 + 规格 + 加料 + 数量（右对齐） |
| 备注 | 单独一行，红色，不与菜品挤在一起 |
| 加菜 | 橙色「加菜」标签，插在对应行 |
| 操作区 | 全部出餐（主）+ 划单（次） |

**字号**：桌号 28、等待时长 22、菜品与加料 18、备注 16、单号与时间 12。
**容器**：卡片内边距 12、左边框 5px 语义色、圆角 12、菜品行高 34。

**展示原则**：宁可换行，**不截断加料与备注**——这两项错了就是做错菜。
多规格时「菜品 + 规格」换行展示，不省略。

---

## 4. 超时分级

| 档位 | 阈值 | 表现 |
| --- | --- | --- |
| 正常 | 小于 5 分钟 | 绿色左边框与计时 |
| 临期 | 5 ~ 10 分钟 | 橙色，边框加深 |
| 超时 | 超过 10 分钟 | 红色，置顶，推店长，主按钮变红 |

- 阈值按门店配置，不在前端写死。
- **不使用闪烁**，避免后厨分神。
- 门店只有一套后厨，阈值不按菜品分类区分。

---

## 5. 操作

| 操作 | 行为 |
| --- | --- |
| 全部出餐 | 该单所有明细一次出餐，卡片淡出移除并提示 |
| 划单 | 展开逐项勾选，可部分出餐，剩余留屏 |
| 批量出餐 | 高峰期可选开启，默认关闭，避免误操作 |
| 撤销出餐 | 出餐后短时间内在「最近出餐」撤销；超时需店长权限并留审计 |

- 「全部出餐」不做二次确认（高频操作，确认反而误事）。
- 划单收起后保留已勾选状态。
- 一期数量按整行勾选，不做拆份。

---

## 6. 外卖接单卡片

外卖与自提单需先接单再制作，卡片顶部多一条接单栏：

- 显示平台与平台单号、自动拒单倒计时。
- 接单与拒单等宽；拒单需选原因（缺货、太忙、已打烊、超区）。
- 门店开启自动接单时不显示接单栏，直接进入制作。
- 倒计时结束自动拒单并提示。

---

## 7. 加菜、退菜与催单

| 事件 | 表现 |
| --- | --- |
| 加菜 | 插入橙色「加菜」行，不重排、不重置计时 |
| 退菜（未出餐） | 该行划线灰化，卡片保留 |
| 退菜（已出餐） | 不在本屏处理，走售后 |
| 全部退回 | 卡片移除并提示 |
| 催单 | 加红色角标与次数，置顶；不弹窗 |

---

## 8. 异常

| 状态 | 表现 |
| --- | --- |
| 连接正常 | 顶部绿色「已连接」 |
| 断线 | 红色「重连中」，保留最后数据但置灰不可点 |
| 重连成功 | 自动全量刷新 |
| 无单 | 居中「暂无待出餐订单」 |
| 操作失败 | 提示原因并刷新真实状态 |

**断线期间禁止本地标记出餐**，否则屏幕与系统不一致。

---

## 9. 与打印

- 堂食下单、外卖/自提支付成功打厨打单；加菜打增量，退菜打退菜单。
- **出餐不打印**，靠屏幕确认，避免浪费纸。
- 屏幕与纸单同源生成；打印失败不回滚订单。

---

## 10. 快捷键

| 键 | 行为 |
| --- | --- |
| Enter | 当前卡片全部出餐 |
| Space | 展开或收起划单 |
| Esc | 收起 |
| 方向键 | 卡片间移动 |
| R | 最近出餐撤销 |

---

## 11. 需与后厨确认

1. 一屏几张卡：3 / 4 / 4 列压缩。
2. 排序：超时优先（默认）还是纯时间。
3. 划单默认收起还是展开。
4. 是否需要批量出餐。
5. 超时阈值按门店定多少。
6. 数量是否拆份出餐。
7. 谁可以撤销出餐。
8. 是否需要语音播报新单。
