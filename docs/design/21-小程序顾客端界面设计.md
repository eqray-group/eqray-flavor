# 21 · 小程序顾客端界面设计

> 上一份：[20 POS 收银](./20-POS收银界面设计.md)｜返回：[文档总览](./README.md)

**一句话**：扫码 3 次点击到菜单，金额只信服务端，支付失败不重复下单。

---

## 1. 目标

| 目标 | 度量 |
| --- | --- |
| 扫码即达 | 扫码到菜单不超过 3 次点击 |
| 单手操作 | 主操作位于屏幕下三分之一 |
| 金额可信 | 金额全部来自服务端试算 |
| 可追踪 | 购物车到支付的流失可统计 |

---

## 2. 页面地图

- 扫码 / 首页 → 菜单 → 菜品详情 → 购物车 → 确认订单 → 支付 → 订单跟踪
- 订单跟踪 → 加菜 / 评价 / 退款申请
- 会员中心 → 我的券 / 积分 / 储值卡 / 地址 / 我的订单

---

## 3. 扫码落地

顶部展示门店名与地址，桌号大字突出，标注营业状态；主按钮「开始点餐」。

异常：

- 门店休息：禁用按钮并提示暂不接单。
- 未开启线上点餐：提示联系店员。
- 桌码无效：提示重新扫码。

---

## 4. 菜单页

| 区域 | 规则 |
| --- | --- |
| 顶部门店栏 | 门店名 + 会员中心入口 |
| 左侧分类 | 固定宽度，锚点吸顶，当前分类高亮 |
| 右侧菜品 | 单列卡片，含图片、菜名、标签、价格、加购按钮 |
| 底部购物车 | 固定，显示件数、金额、去结算 |

- 沽清菜品整体灰化并标注「已售罄」，不可点。
- 非会员展示会员价对比，点击引导开通。
- 分类与滚动联动：点分类滚动到分区，滚动时自动高亮分类。
- 下拉刷新菜单，沽清实时生效。

---

## 5. 菜品详情

- 顶部大图，名称与描述。
- 规格单选，未选禁用加购。
- 加料组：必选组标注「必选」，多选组可跳过。
- 备注输入口味与忌口。
- 底部数量、价格、加入购物车；价格随选择实时变化。

---

## 6. 购物车

- 展示菜品、规格、加料、数量与单价，可增减与清空（清空需确认）。
- 数量减到 0 提示移出。
- 同桌合并：同一桌台的订单归入同一台位单。
- 合计与已优惠金额由服务端计算。

---

## 7. 确认订单

按「商品小计 → 活动优惠 → 券 → 积分 → 储值卡 → 应付」顺序展示，每项标明来源。

| 模块 | 规则 |
| --- | --- |
| 选券 | 弹层列出可用券；不可用置灰并给原因（如不适用当前门店） |
| 积分 | 可输入抵扣分值，达到上限时提示 |
| 储值卡 | 展示余额，可勾选抵扣 |
| 就餐人数 / 备注 | 可选填写 |
| 金额 | 只展示，不可编辑 |

---

## 8. 支付

| 状态 | 表现 |
| --- | --- |
| 调起 | 直接透传服务端返回的支付参数 |
| 支付中 | 遮罩与提示 |
| 成功 | 跳转订单详情并提示成功 |
| 失败或取消 | 停留原页，可重新支付，订单保留 15 分钟 |
| 超时 | 提示订单已关闭 |

> 支付失败**不重复创建订单**，用同一订单重新支付。

---

## 9. 订单跟踪

- 状态时间轴：已支付 → 制作中 → 待取餐 → 已完成。
- 自提单取餐码大字展示。
- 加菜只对堂食进行中的订单（并入台位单）；外卖/自提支付后需另下新单，见 [05 §7](./05-核心业务流程设计.md)。
- 催单限制频次（如 5 分钟一次）。
- 退款申请按订单状态决定是否可申请。

---

## 10. 会员中心

| 模块 | 内容 |
| --- | --- |
| 会员卡 | 等级、成长值进度、距下一级差距 |
| 积分 | 当前积分、即将过期积分 |
| 我的券 | 未使用 / 已使用 / 已过期 |
| 储值卡 | 余额与充值入口 |
| 我的订单 | 订单列表 |
| 地址 | 外卖收货地址 |

**充值**：按档位展示「充多少送多少」，显示当前余额，充值走统一支付。

---

## 11. 外卖差异

| 差异 | 说明 |
| --- | --- |
| 入口 | 首页选择「外送」 |
| 地址 | 从地址簿选择或新增 |
| 校验 | 超范围提示并推荐附近门店 |
| 费用 | 展示打包费、配送费与起送价 |
| 时效 | 显示预计送达时间 |

---

## 12. 交互规范

- 适配底部安全区。
- 加载用骨架屏，列表下拉分页。
- 空态插图 + 引导操作。
- 轻提示 2 秒，重要信息用弹窗。
- 支付未完成返回时提示「订单未支付，是否离开」。
- 下单按钮点击后置灰，配合请求号防重复。
- 所有金额服务端返回，前端只格式化展示。

---

## 13. 落地要点

1. 菜单本地缓存，弱网展示上次结果并提示可能不是最新。
2. 长列表用滚动联动，避免卡顿。
3. 图片走文件服务 + 懒加载 + 占位图。
4. 支付前必须试算，支付后以服务端订单状态为准。
5. 状态用轮询或订阅消息刷新，不假设前端状态正确。
