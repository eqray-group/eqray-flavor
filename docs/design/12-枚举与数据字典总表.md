# 12 · 枚举与数据字典

> 上一份：[11 加盟结算与对账](./11-加盟结算与对账.md)｜下一份：[13 测试设计](./13-测试设计.md)

**一句话**：判定逻辑用代码枚举，展示标签用字典；两边数值必须一致。

---

## 1. 约定

| 场景 | 用法 |
| --- | --- |
| 状态机流转 | 代码枚举 + 流转白名单 |
| 需要运营配置标签 / 颜色 | 字典为主，代码枚举同值 |
| 强类型判定（金额、类型） | 代码枚举 |

- 字典只负责展示，不承载判定逻辑。
- 字典值一旦上线不可修改，只能新增。
- 仓库已有 `common_status`（禁用/启用）与 `user_gender`，不要重复建。

---

## 2. 业务字典

| 字典 | 值 |
| --- | --- |
| `store_type` | 总部 / 大区 / 门店 |
| `store_status` | 营业 / 休息 / 装修 / 停业 |
| `store_role_type` | 店长 / 收银 / 后厨 / 服务员 / 骑手 |
| `store_rider_status` | 1 空闲 / 2 接单中 / 3 配送中 / 4 休息 / 5 停用 |

| `store_settle_mode` | 后结算 / 分账直连 |

> `store_rider_status` 的「接单中」是可抢单的在线态，不是配送单的待接单；只有该状态
> 且 `current_orders < max_orders` 时才能抢占新单。停用不影响历史记录。

---

## 4. 维护约定

新增状态值必须四步齐全：

1. 字典加值；
2. 代码枚举同值；
3. 更新本文档；
4. 涉及状态机的更新 [05 §1](./05-核心业务流程设计.md) 白名单。

颜色约定：成功 / 警告 / 危险 / 信息 / 主色，对应前端标签样式。
