# 10 · 初始化与数据导入

> 上一份：[09 设备接入与打印](./09-设备接入与打印对接.md)｜下一份：[11 加盟结算与对账](./11-加盟结算与对账.md)

**一句话**：建库、建店、导菜品、导库存，四步上线；能用模板复制就不手工配。

---

## 1. 初始化的四层

| 层 | 内容 | 时机 |
| --- | --- | --- |
| 框架层 | 菜单、角色、字典、超管账号 | 建库时由迁移与种子完成 |
| 业务字典 | 门店、订单、菜品、券、活动等字典 | 建库时 |
| 基础数据 | 品牌根节点、门店、桌台、打印机、员工 | 上线前 |
| 经营数据 | 菜品库、门店菜单与价格、库存期初、券模板 | 上线前与日常 |

**顺序**：建库 → 业务字典 → 品牌根节点 → 门店与员工 → 菜品库 → 门店菜单与价格 →
库存期初 → 券模板与会员规则 → 试营业 → 正式上线。

> 「框架层」与「业务字典」都必须是幂等迁移，且登记在迁移注册表中，不能手工执行 SQL。

---

## 2. 品牌与组织

- 系统第一条数据是**品牌总部根节点**，全库唯一。
- 根节点是虚拟节点，不接单，状态为休息。
- 大区挂根，门店挂大区或直接挂根。

---

## 3. 建店向导

| 步骤 | 内容 |
| --- | --- |
| 1 门店信息 | 名称、编码、地址与坐标、联系电话 |
| 2 营业设置 | 营业时间、是否自动接单、是否开放线上 |
| 3 配送规则 | 配送范围、起送价、配送费（外卖店） |
| 4 桌台 | 区域与批量生成桌台、桌码 |
| 5 设备 | 打印机与厂商参数 |
| 6 员工 | 分配店长、收银、后厨、服务员 |
| 7 菜单 | 引用品牌菜单或从模板复制 |

- 支持中途保存，此时门店为「装修」状态，不可下单；完成后转「营业」。
- 每一步都有默认值，不强迫一次填完。

---

## 4. 门店模板复制

目标：新店配置上线不超过 1 天。

| 复制项 | 说明 |
| --- | --- |
| 菜单结构 | 可只复制上架项 |
| 门店价格 | 支持按比例或绝对值，避免异地差价照搬 |
| 配送规则 | 范围必须按新址重设 |
| 打印机 | 设备号需重新绑定 |

规则：

- 事务内批量复制，已存在的项默认跳过，不覆盖。
- 生成差异报告（新增、跳过、失败）。
- 源门店与目标门店不能相同。

---

## 5. 批量导入

**支持导入**：菜品分类、菜品与规格、加料组与加料、菜品加料绑定、门店可售与沽清、
门店价格覆盖、库存期初、券模板。

**菜品导入模板**（一表多行，一行一个规格）：

| 列 | 必填 | 校验 |
| --- | --- | --- |
| 分类名称 | 是 | 二级分类用「父/子」表示，不存在可自动创建 |
| 菜品名称 | 是 | 同分类下唯一 |
| 规格名称 | 是 | 同菜品下唯一 |
| 标准价（元） | 是 | 大于 0，两位小数 |
| 会员价（元） | 否 | 不高于标准价 |
| 成本价（元） | 否 | 不小于 0 |
| 单位 | 否 | 默认「份」 |
| 标签 | 否 | 逗号分隔 |
| 图片 | 否 | 需先上传到文件服务 |
| 加料组 | 否 | 逗号分隔，组需已存在 |

**金额单位**：Excel 用元，入库统一转分，换算由导入器负责。

**导入规则**：

1. 校验先行：必填、格式、引用存在性、唯一性。
2. 小批量（数千行内）同步处理，任一行不合法则整批拒绝，返回带行号与原因的回执。
3. 大批量走异步任务：先返回批次号，后台分批写入，回执给成功与失败数及错误文件。
4. 幂等：按业务唯一键判断，存在则更新或跳过，由导入模式决定。
5. 引用完整：导入规格前菜品必须存在，导入门店价前门店必须已发布该规格。
6. 每次导入留批次日志：类型、文件、总行数、成功与失败数、错误文件、耗时、状态。

## 6. 历史数据迁移

| 步骤 | 内容 |
| --- | --- |
| 1 盘点 | 梳理旧系统门店、菜品、会员、订单字段 |
| 2 映射 | 建立旧编码到新编码的映射，重点是分类、会员等级 |
| 3 清洗 | 统一金额单位、时间格式，手机号去重 |
| 4 导入 | 基础数据 → 会员 → 券与储值 → 历史订单 |
| 5 校验 | 行数、金额、会员数三方对账 |
| 6 切换 | 低峰停旧写新，旧库只读保留三个月 |

- 历史订单只做归档查询，不参与新流程，不重算状态、支付与积分。
- 会员的积分、成长值、储值余额作为**期初值**导入，走专属入口并留审计。
