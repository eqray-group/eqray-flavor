# 17 · 终端交互设计

> 上一份：[16 外卖平台对接](./16-外卖平台对接设计.md)｜返回：[文档总览](./README.md)

**一句话**：四个终端、一套业务；金额只信服务端，断网时本地兜底但支付必须联网。

---

## 1. 终端矩阵

| 终端 | 用户 | 形态 | 关键约束 |
| --- | --- | --- | --- |
| 微信小程序 | 顾客 | 顾客端 | 弱网、单手操作、扫码入口 |
| 管理后台 | 总部 / 大区 / 店长 | 浏览器 | 表格、表单、权限 |
| POS 收银 | 服务员 / 收银 | Windows / 安卓 | 触屏、键盘、弱网离线 |
| KDS 屏 | 后厨 | 浏览器 / 一体机 | 大字号、高温环境、快 |
| 自助点餐机 | 顾客 | 安卓 | 无人值守 |
| 叫号屏 | 顾客 | 安卓 | 语音播报 |
| 骑手端 | 骑手 | uni-app | 抢单、取货、送达；移动弱网 |

管理端走 `/api/v1/*`，顾客端走 `/api/v1/client/*`。

---

## 2. 顾客端

**主流程**

- 堂食：扫码 → 识别门店与桌号 → 菜单 → 详情与加料 → 购物车 → 试算 → 下单（不支付，直接入厨）→ 用餐中加菜 → 结账 → 订单详情。
- 外卖 / 自提：选店或地址 → 菜单 → 购物车 → 试算 → 下单 → 支付 → 订单详情（取餐码 / 催单）→ 会员中心。

| 页面 | 要点 |
| --- | --- |
| 菜单 | 分类吸顶；沽清置灰不可加购；显示会员价对比 |
| 菜品详情 | 规格与加料组（必选校验）；备注忌口 |
| 购物车 | 同桌聚合；金额实时试算；可用券提示 |
| 试算 / 下单 | 展示完整优惠明细；金额只来自服务端 |
| 支付 | 调起支付；失败可重试；有倒计时 |
| 订单详情 | 状态时间轴；取餐码；加菜与催单 |
| 会员中心 | 等级、成长值、积分、券、储值卡与充值 |

**交互规范**

- 扫码后一屏内完成门店与桌号识别。
- 未支付订单可从「我的订单」继续支付。
- 下单按钮点击后置灰，配合请求号防重复提交。
- 弱网明确提示，不静默失败。

---

## 3. POS

**操作**：开台 → 点单 → 挂单 / 取单 → 并单 / 拆单 → 结账 → 清台；交班按班次单独执行，退款按权限。

**要点**

- 键盘友好：常用动作有快捷键，适配扫码枪。
- 触屏为主：关键按钮足够大。
- 多收银端同步桌台状态，防重复开台。
- 支持储值卡 + 微信组合支付、AA 拆单。
- 断网可本地挂单与点单，恢复后同步；结账必须联网。

---

## 4. KDS

**流程**：新单推送 → 接单 → 制作中 → 出餐 / 划单 → 全部出餐通知前台。
催单只加角标并置顶，超时只高亮，二者都不改变出餐状态（与 19 一致）。

**要点**

- 单列卡片流：桌号、单号、菜品、加料、备注、等待时长。
- 菜品与备注大字号，远距离可读。
- 三色状态：正常、临期、超时；超时高亮，阈值可配。
- 支持批量出餐；加菜实时插入、退菜实时移除，不重打整单。
- 断线自动重连，并用全量拉取兜底。

---

## 5. 自助机与叫号屏

| 终端 | 流程 | 要点 |
| --- | --- | --- |
| 自助机 | 扫码登录 → 点餐 → 支付 → 取号 | 无人工；超时退出；支持游客下单 |
| 叫号屏 | 接收备餐完成 → 播报取餐号 | 语音 + 大字；多窗口分流 |

---

## 6. 状态提示

| 状态 | 提示 |
| --- | --- |
| 沽清 | 置灰 + 已售罄 |
| 门店休息 | 拦截下单 + 门店休息中 |
| 未支付超时 | 倒计时 + 关单提示 |
| 库存不足 | 下单前提示 |
| 券不可用 | 置灰 + 原因（如不适用当前门店） |
| 订单状态 | 时间轴展示 |

> 提示文案统一取服务端返回，前端不硬编码。

---

## 7. 弱网与离线

| 场景 | 策略 |
| --- | --- |
| 小程序弱网 | 重试 + 明确提示；菜单可缓存上次结果 |
| POS 断网 | 本地挂单与点单，恢复后批量同步；支付不可离线 |
| KDS 断网 | 自动重连 + 全量拉取；纸单兜底 |
| 冲突 | 以服务端为准，本地重复单去重 |

---

## 8. 交互检查

- [ ] 扫码到菜单不超过 3 次点击
- [ ] 所有金额来自服务端试算
- [ ] 沽清、休息、不可用券有置灰与原因
- [ ] 下单防重复提交
- [ ] POS 断网可挂单并恢复同步
- [ ] KDS 断线可重连并拉全量
- [ ] 颜色不单独承载信息，配文字或图标
- [ ] 支付失败或取消有清晰回流路径
