## 下午：pay 模块按 yudao 逐项校正

基线：`ruoyi-vue-pro` commit `5656a0b`（用 gitee API + raw 抓源码核对，未凭记忆）。

**yudao 实际取值（已核实）**
- `PayOrderStatusEnum`：WAITING 0 / SUCCESS 10 / CLOSED 20，**无退款状态**（全额退款只累加 refund_price）
- `PayRefundStatusEnum`：CREATE 0 / SUCCESS 1 / FAILURE 2 / CLOSE 99
- `PayNotifyStatusEnum`：WAITING 1 / SUCCESS 2 / FAILURE 3 / REQUEST_SUCCESS 4 / REQUEST_FAILURE 5
- `PayNotifyTypeEnum`：ORDER 1 / REFUND 2（无 TRANSFER）
- `PayNotifyTaskDO.NOTIFY_FREQUENCY`：[15,15,30,180,1800,1800,1800,3600] 秒，8 档 + 首次 = 9 次
- `pay_notify_task` 字段**不含** merchant_refund_id（曾误加，已回滚）
- master 的 pay 模块 dataobject 只有 merchant/notify/order/refund，**无 wallet、无 transfer 实现**；钱包与转账是本项目扩展
